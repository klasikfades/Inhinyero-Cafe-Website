# Café Landing Page

Static HTML/CSS/JavaScript café website template.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and menu tabs
- `images/` — replace placeholder images with the café's photos

## Before publishing
Edit `index.html` and replace:
- HAVEN CAFÉ with the real café name
- address
- opening hours
- phone/email
- menu items and prices
- Facebook URL
- Google Maps URL/location

Put the café's image files inside `images/` using these names:
- `hero.svg initially / .jpg when replaced`
- `about.svg initially / .jpg when replaced`
- `photo1.svg initially / .jpg when replaced`
- `photo2.svg initially / .jpg when replaced`
- `photo3.svg initially / .jpg when replaced`

## Deploy
Upload the folder contents to a GitHub repository, then import the repository into Vercel. No Node.js or build command is required.
