# Café Editorial Landing Page

A static café website inspired by the clean, editorial one-page style of the reference site.

## No Node.js required

Upload these files directly to GitHub and import the repository into Vercel.

## Files

- index.html
- style.css
- script.js
- images/

## Customize

Edit `index.html` for:
- café name
- menu and prices
- story
- hours
- address
- phone
- Facebook URL
- Google Maps location

Replace the placeholder SVG files in `images/` with real JPG/WEBP photos using the same filenames, or update the image paths in `style.css`.

## Vercel

No framework or build command is required. Keep `index.html` in the repository root.
